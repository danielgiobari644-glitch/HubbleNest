Ways to reach us

We keep this simple on purpose.

Inside the app (fastest)

Open the sidebar → Get Help runs the Connection Doctor, which diagnoses most issues live and can fix stale caches in one click.

Email

Write to the project owner through the contact address published in the app’s README — responses usually arrive within a couple of days.

Security reports

Found a security issue? Please describe it in detail via the same contact channel. We treat reports as confidential and fix genuine issues fast.

Data requests

Ask for an export or deletion of your account data through any channel above; requests are honoured from the Firestore project of record.
