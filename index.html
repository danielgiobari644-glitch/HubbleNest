Saved here once, stored in this project's Firestore, and reused by every future deploy — you never paste keys into files again. Get the Web Push key from Firebase Console → Project Settings → Cloud Messaging → Web Push certificates. The service account fields (Firebase Console → Project settings → Service accounts) enable background delivery through Firebase Cloud Messaging.

AI configuration — admin setup (optional)

Paste a free Google AI Studio key to switch on the platform AI — it writes full custom Arcade games from prompts AND powers every HubbleNest Bot conversation and the Get Help assistant. Get it at aistudio.google.com → Get API key: Google now issues secure "AQ." Auth keys (they start with "AQ."); classic "AIza" keys are accepted while they still work. Stored once in this project's Firestore like the push config — it survives every redeploy. Without a key the Arcade still generates real playable games with its built-in game engine.

Valid models: gemini-2.5-flash (recommended), gemini-2.0-flash or gemini-flash-latest. The Test button sends one real request and reports the exact result — so an invalid, expired, retired or restricted key can never hide behind a generic error.
