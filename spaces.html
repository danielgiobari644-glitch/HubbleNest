A Space for every group you belong to

A Space is your group’s private home inside HubbleNest: real-time chat, announcements, a files library, links, and member management — joined with a code or QR in seconds.

How Spaces work

Spaces are designed to be safe by default and effortless to join.

Create in a minute

Pick a name, category and cover. HubbleNest generates a unique code like HN-7K4P92 plus a scannable QR invite.

Join instantly with a code

Anyone with a valid Space code becomes a member the moment they press Join — no waiting for approval. The code is the invitation.

Chat & announcements

Rich-text messages with reactions, replies and attachments. Administrators can pin announcements that stay on top.

Files & links library

Every shared file and link is collected into a searchable library, so nothing gets lost in the scroll.

Member management

Administrators add members straight from their contacts and can remove members or promote co-admins at any time.

Temporary Spaces

Set an expiry date for time-boxed groups — study weeks, events, projects — with clear countdowns and renewal controls.

Private by default

A Space is visible only to its members. Nothing inside a private Space — messages, files, or the member list — is published to the web. A Space can only ever appear on a public page if its administrator explicitly turns on the public-intro setting, and even then only the name, description and member count are shown: never the conversation.

Built for real groups

Classrooms use Spaces for coursework and submission Q&A. Fellowships run weekly announcements. Project teams keep decisions and files in one searchable place. Whatever the group, the pattern is the same: one code, one home, everything connected.
